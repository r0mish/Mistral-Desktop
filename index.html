Recherche web

SearXNG : activez le format JSON (search.formats: [html, json] dans settings.yml). Les pages lues par fetch_url sont téléchargées depuis votre machine ; les adresses du réseau local sont bloquées.

Serveurs MCP

Même format que Claude Desktop. Serveurs locaux (command) ou distants (url + headers). Protocole MCP 2026-07-28, avec repli automatique pour les serveurs plus anciens.

Agent de code

L'agent ne peut lire et écrire que dans le dossier de projet choisi. Les commandes s'exécutent avec vos droits : en mode « Tout demander » ou « Modifs auto », chacune doit être approuvée.
